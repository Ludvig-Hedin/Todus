# Todus New Website

Standalone marketing site exported from Relume and adapted for Todus.

## Scripts

- `npm run dev` starts the Vite dev server.
- `npm run build` builds the static site.
- `npm run preview` previews the production build locally.
- `npm run format` formats the site with Prettier.
